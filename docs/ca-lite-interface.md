# 证书模块接口边界

私有 PKI 已内置于当前 Python 程序，不再调用外部 ca-lite，也不保留旧命令或 JSON 兼容层。本文档约束当前证书接口；产品规则见 [产品基线](product.md)。

## 私有 PKI

实现位于 `app/network/certificates.py`，通过 `Application.certificates` 调用。证书、私钥和 P12 的生成全部使用 Python cryptography，不调用 OpenSSL CLI。

- 初始化唯一根 CA 及 TLS、Client、中继三个中间 CA。输入统一名称前缀，CN 分别追加 `Root CA`、`TLS CA`、`mTLS CA`、`Relay CA`；`names` 返回实际保存的角色名称映射，既有证书不自动重签。
- 自动站点和中继证书只在批次生成时签发，保存到批次材料中。
- Client 手动签发并持久化，名称唯一，可启用、禁用、导出，不提供单项删除。
- 新建 CA 的名称前缀与 Client 名称仅允许英文字母、数字、空格及 `- _ .`，保存前去掉首尾空白；CA 名称追加后缀后也须满足 CN 长度限制。既有名称保持原样。
- `overview()` 读取各 CA 与 Client 证书的实际 CN、到期日期及 Client 启用状态，用于树状展示；仅解析公开证书，不解密私钥，无须解锁。
- 信任 CA 导出根证书，DER `.cer`；P12 使用用户指定的独立导出口令。
- 重新初始化 CA 清除全部私有 CA 和 Client 材料，保留区域、节点、站点配置及独立公共证书记录。

## 公共 TLS

实现位于 `app/network/public_tls.py`，通过 `Application.public_tls` 调用。每条记录独立持有 DNS 凭据；配置由测试与正式环境共用，证书、私钥及 ACME 工作状态按环境独立保存。lego 负责 Let’s Encrypt 协议，应用负责加密存储、材料检查、失败保留旧证书。

`certificate_policy.py` 定义申请域名范围、读取实际证书有效期及 13 天续签阈值。界面预检查和执行路径共用该规则，不以数据库展示字段替代实际证书有效期。

签发返回独立的状态与文案。批次编排只选择所需记录并调用此模块，生成器仅接收证书和私钥，不访问公共证书库或 ACME。

## 保护与校验

所有持久私钥、DNS 凭据及 ACME 私密状态由统一程序口令保护；口令仅在本进程解锁期间持有。改密原子重加密全部受保护材料。P12 导出口令和危险操作再次验证不改变这一边界。

解锁后检查私钥匹配、实际域名范围、有效期及所提供证书链的签名；不在日志、错误或界面输出私钥与 DNS 凭据。配置批次材料由独立随机密钥加密，此密钥受程序口令保护；导出的部署包使用独立口令加密。SSH 部署的临时包与目标机运行材料含明文私钥，按敏感材料处理。
