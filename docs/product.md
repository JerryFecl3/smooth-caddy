# 产品与交互基线

本文件记录当前产品规则、模块边界及 TUI 交互基线。
当前实现支持配置维护、证书管理、设置存档、JSON 导入导出、部署包导出与 SSH 部署。业务逻辑独立于 TUI，可通过 Python 接口调用。

## 定位与范围

面向个人和爱好者，在家庭／工作网络部署变化时维护一套多节点 Caddy 配置。
一个程序实例只管理一个网络；不提供多项目、多租户或多网络切换。
核心是区域、节点、站点三套配置编织成矩阵，加上配套证书管理。
所有节点自然承载所有站点，新增对象自动扩展矩阵；无逐站点节点绑定、无节点级站点规则覆盖。
不管理 DNS、iptables、nftables、NAT、端口映射、包升级清理或通用系统维护。
导出生成每节点离线 `.run` 部署包；可手动安装，也可由配套 SSH 流程上传并执行。SSH 与部署属于外围能力，复用相同发布物，不承担通用日常运维。

## 区域

全局区域名称唯一。默认提供内网、外网，可以增加 VPN 等区域。
每个区域仅提供默认 TLS 来源与默认 mTLS 开关，端口由节点配置。
无区域继承、优先级或区域间自定义路由。
新增区域时：已有节点对应区域关闭，已有站点对应区域不提供服务。

## 节点

节点名称唯一，改名不改变身份和引用。
节点明确配置平台类型与 CPU 架构，供导出选择安装脚本、服务定义和官方二进制。界面平台候选仅显示 Debian、OpenWrt，平台和架构均使用互斥勾选项；未选择时不自动指定。持久平台标识及现有安装器目标保持 Debian 13 与 OpenWrt 25.12；安装器不自动识别或改选平台。
每个节点区域配置启用状态、绑定 IP 列表 `ips`、HTTP、HTTPS 与中继 HTTPS 三个独立端口（初始值 80、443、8443），不再继承区域端口。全部地址共用端口。中继服务由节点—区域的 `relay_enabled` 单独控制，新配置默认 false；启用后端口输入默认 8443，必须填写有效端口，不另设覆盖开关。关闭中继时不生成监听或服务端证书，其保留端口不参与有效性和冲突检查。连接业务上游不受本地中继开关影响。升级旧配置时将原区域的中继开关设为 true，保留原端口；新存档格式 5 包含此开关。
HTTP 跳转端口归节点—区域独立配置，修改一个区域不影响其他区域。生成配置按 HTTP 端口及地址族汇总监听；相同地址与 HTTP 端口可合并跳转路由，同一监听范围、同一域名对应多个 HTTPS 目标时标错。不同 HTTP 端口独立，不提供纯 HTTP 代理。
启用区域时至少填写一个 IP，多行输入、每行一个地址，规范化并去重。`0.0.0.0` 仅监听全部 IPv4，`::` 仅监听全部 IPv6；配置分别使用 `tcp4/地址:端口` 和 `tcp6/[地址]:端口`。拒绝域名、端口、多播和带 scope 的地址，IPv4-mapped IPv6 规范化为 IPv4。
没有额外中继开关；区域启用后中继入口随之启用。HTTPS／中继端口在同一节点、同族重叠地址上不能重用，冲突双方区域同时标错；也不能与重叠地址上的任一区域 HTTP 跳转端口相同。不同节点独立，关闭区域不参与。节点区域编辑时，格式错误及该区域监听冲突拒绝保存。

节点之间没有父子关系，列表按保存顺序平铺。每个节点有可选字符串 `upstream_url`：留空直接访问各站点源头；填写 HTTPS URL 则全部站点、全部入口经该中继转发。支持域名、IPv4、方括号 IPv6 和可选端口（省略为 443），允许末尾斜杠，不接受用户名密码、路径、查询参数、片段、通配或多播地址。

上游地址可指向未登记在本实例节点列表中的兼容中继，但双方必须属于相同的中继 CA 信任体系。上游地址不引用节点或区域；删除、改名、修改其他节点不会改变此 URL。当前只支持单个上游地址，不做故障转移或拓扑环路检测，部署者须避免循环转发。中继监听仅在区域和中继服务都启用时生成，使用该节点区域的独立中继 HTTPS 端口。

## 站点

站点名称唯一，域名另行全局唯一；一个站点只有一个域名，多个域名使用多条站点。
源头暂为不带路径、查询参数或片段的 http/https URL，可指定端口。
当前只支持单源头。
普通 HTTP/API/WebSocket 共用代理规则，不设 WS 开关。

源地址弹窗同时编辑 `homepage_redirect`（首页跳转路径，默认空）和 `allowed_paths`（允许的目录前缀列表，默认空）。只接受本站以单个 `/` 开头的路径，路径部分不接受查询参数、片段、反斜杠、空白、控制字符、通配符、占位符、百分号编码、重复斜杠和 `.`／`..` 路径段；首页跳转可附加查询参数，查询参数原样保留，允许合法百分号编码，但拒绝空白、控制字符、反斜杠、片段和未编码的 `{}` 占位符。首页跳转的路径不能为 `/`，包括带参数的根路径，以免循环跳转。空允许列表表示不限制；`/s` 与 `/s/` 都允许 `/s` 本身及 `/s/` 下的路径，但不允许 `/something`。`/` 前缀允许所有路径。设置跳转时先匹配根路径并返回 302，Location 为配置路径及配置查询参数（不合并原请求查询参数）；跳转目标的路径部分必须在允许范围内，否则标记源地址配置错误并阻止生成。启用 mTLS 时，TLS 握手先验证客户端证书，通过后才处理首页跳转；参数对已授权前台用户可见。其余请求匹配任一前缀才代理，否则返回 404。允许请求的路径及查询参数不改写，HTTP/API/WebSocket 使用同一入口规则；中继端口不重复执行这些规则。

数据库版本 11 在完整备份后为旧站点补充空跳转和空路径列表，不改变既有访问行为。存档／JSON 格式 5 保留两项设置，读取格式 1～4 时补默认值；旧数据库中的存档按原格式保留并在读取时兼容，不改写历史存档。


每个站点区域保存 `Service(enabled, tls_source, mtls)`。启用即 HTTPS，关闭不提供用户服务；TLS 来源与 mTLS 可分别继承区域默认值（null）或显式覆盖。区域仅保存默认 TLS 来源（私有 CA／公共 CA）和默认 mTLS 开关，新区域默认私有 CA、关闭 mTLS，不控制服务启停。站点在新区域默认关闭。
同一站点可在不同区域使用不同 CA，生成独立的证书材料标签并按对应监听选择。公共证书匹配与申请根据生效策略确定；不存在站点级 TLS 来源。

无站点总开关；各区域关闭即可暂停用户服务。进入站点路由后的未知域名、未开放协议统一拒绝，无兜底站点。

所有网站 HTTPS 监听默认启用 Caddy `http_redirect`，在 `tls` listener wrapper 之前识别误入的明文 HTTP 请求并返回 308，保留请求 Host（含显式端口）及路径、查询参数，将协议改为 HTTPS。该跳转发生在 TLS 握手和站点路由之前，不按域名或站点服务方式筛选；跳转后的 HTTPS 请求仍受站点规则及 mTLS 校验约束。HTTP 监听只提供跳转，中继 HTTPS 监听不启用此包装器，端口冲突校验保持不变。已有批次不改写，须部署当前设置才能生效。
中继不受中继所在区域的站点用户服务规则限制：区域不开放某站点，并不妨碍转发它。
用户入口验证用户，中继每一跳只验证双方节点，不再次验证用户身份。
所有中继使用 TLS + mTLS。

站点“源地址”弹窗同时编辑地址与“校验 HTTPS 源证书”勾选项，逐站点保存，新站点默认不勾选。勾选时验证该 HTTPS 源证书的信任链和名称；不勾选时仅对该站点直连 HTTPS 源设置 `insecure_skip_verify`。HTTP 源、用户入口及节点间 TLS/mTLS 不受影响。保存后需重新部署才生效。旧配置的全局校验值迁移到各已有站点，保留原行为；不再提供站点页高级设置入口。

## 配置数据标识

持久化配置与业务判断使用固定英文标识，显示文字由 TUI 映射。界面支持简体中文（`zh-CN`）与英文（`en`），启动时自动检测系统语言。Windows 使用当前用户的显示语言；Linux 按 `LC_ALL`、`LC_MESSAGES`、`LANG` 的优先级检测，无环境变量时读取系统消息区域设置。所有中文区域使用简体中文，包括 `zh-CN`、`zh-SG`、`zh-TW`、`zh-HK`、`zh-MO`、`zh-Hans`、`zh-Hant` 和单独的 `zh`；不进行自动简繁转换。其他语言、`C` / `POSIX` 或检测失败时使用英文。不保存语言偏好、不提供切换按钮，旧 `ui.json` 不再读取或改写；`--language` 可临时覆盖自动检测，仅影响本次运行。启动入口在加载界面模块前确定语言，不支持运行中即时切换。导航、表单、帮助、业务提示和任务进度使用集中式文案目录；用户输入的名称、域名、证书内容及外部工具原始输出不翻译。语言设置不改变业务配置或证书字段。

| 字段 | 持久化值 | 中文显示 |
| --- | --- | --- |
| TLS 来源 | `private_ca` / `public_ca` | 私有 CA / 公共 CA |
| 区域服务策略 | `enabled`、`tls_source`、`mtls` | 服务启停、TLS 来源与 mTLS；后两项 null 表示继承 |
| 节点平台 | `debian_13` / `openwrt_25_12` | Debian / OpenWrt |

未选择平台继续使用空字符串；未填地址、域名、端口错误及失效引用等草稿仍可保存。未知枚举值或在新格式中写入中文显示文字会被拒绝，不静默猜测或回退为其他行为。兼容旧值仅发生在版本 2 数据库迁移与格式 1 批次解码边界。

## 证书体系

唯一私有根 CA，三个中间 CA：站点 TLS、用户 Client、中继。
所有新生成的私有 CA、Client、网站及中继证书保留现有 CN，并固定加入主体字段 `OU = Smooth Caddy`，用于标示生成程序，不参与授权、不提供编辑。已有证书不自动重签；公共 CA 签发的证书不修改。
站点用户入口可选择私有 CA 或公共 CA；用户 mTLS 与中继身份仍使用私有 CA。公共 CA 由独立 lego 模块管理，详见公共 TLS 章节。
私有证书与密钥的生成、签发、加密、改密和 PEM／P12 编解码通过 Python `cryptography` 库在进程内完成，不调用 `openssl`；公共 TLS 证书申请通过 lego 完成。
CA 初始化输入名称前缀（示例 Personal WEB），四个 CN 强制追加 Root CA、TLS CA、mTLS CA、Relay CA。名称保存与证书 CN 一致；既有证书保持原名，不自动重签。程序口令独立于 CA 初始化。
四个 CA、所有 Client、SSH 私钥统一使用程序口令加密保存。首次启动设置口令并立即生成 SSH 密钥，随后必须创建 CA 才能进入主界面；中途返回退出程序，下次启动继续补全。已有口令但缺失 SSH 身份或 CA 时，启动要求解锁后补全；初始化完整时首次受保护操作要求解锁，同一进程持续有效，退出清除会话。公共 TLS 的私钥、DNS 凭据及 ACME 私密状态使用相同口令保护。

| 材料 | 有效期 | 生命周期 |
| --- | --- | --- |
| 根 CA 与三个中间 CA | 固定到 2099-12-31 | 初始化生成，持续保留 |
| 私有网站 TLS 证书及私钥 | 签发日起 365 天 | 每次部署或导出 .run 时重新签发 |
| 中继服务端／客户端证书及私钥 | 签发日起 365 天 | 每次部署或导出 .run 时重新签发 |
| 用户 Client 证书及私钥 | 固定到 2099-12-31 | 手动签发，持久保存 |

私有 PKI 在数据库中保存四个 CA 与用户 Client 及其私钥；公共 TLS 模块独立保存申请所得的证书与私钥。自动签发的私有网站和中继叶子材料仅在内存生成及临时组包时使用，不写入持久存档或证书数据库；导出 .run 包含目标机运行材料。

固定终止时间为 2099-12-31 23:59:59 UTC；子证书有效期不得超过签发者有效期。上述 365 天规则只适用于私有自动签发，公共证书有效期由 CA 决定。
网站、用户、节点身份不得因共用根 CA 而混用。
每个中继入口拥有独立服务端证书、需要连接中继的节点拥有独立客户端证书。服务端证书的 DNS SAN 统一包含 `relay.smooth-caddy.internal`，出站 TLS 的 `server_name` 固定为此名称，无需 DNS 解析；实际连接的 host 和 port 均来自上游地址 URL，可与目标节点的监听地址、端口不同，以支持 NAT 和端口映射。服务端证书包含全部具体绑定 IP 的 SAN，通配地址不写入 SAN。双方验证专用中继 CA 链及各自的 SERVER_AUTH / CLIENT_AUTH 用途，不使用节点叶子白名单，不关闭证书验证。原始 HTTP Host 与请求 URI 保留，中继的 `strict_sni_host` 为 false，允许固定 TLS 名称与站点域名不同。
持有同一中继 CA 下有效客户端证书的节点可以连接任意中继入口，包括未登记在当前节点列表中的节点。用户 Client CA 与中继 CA 分离，用户 mTLS 仍要求启用 Client 叶子白名单。删除节点或修改上游不撤销已签发的中继证书；当前没有单节点中继撤销机制。源头 HTTPS 的不校验选项不影响中继验证。
整套材料统一导出，换证衔接由配套部署工具负责，本项目不增加过渡信任流程。旧批次的节点绑定证书与 Caddy 文件保持原样，新旧中继认证配置不保证互通；升级需为所有参与中继的节点重新准备运行材料，在维护窗口协调部署，期间可能中断，不提供混合版本自动过渡。

Client：仅输入唯一签发名称，默认启用；可禁用、恢复、导出，不可单独删除，禁用名称仍占用。
所有用户 mTLS 入口固定为 CA 校验 + 启用 Client 的叶子白名单，无按站点授权，无认证模式开关。
空白名单拒绝全部 Client。签发、禁用、恢复要在节点更新后生效。
可单独导出 Client P12（证书、私钥、证书链），导出时输入密码。
“导出信任 CA”导出根 CA 的公开证书，默认文件名 `root-ca.cer`，DER 编码，不含私钥、不需要导出密码或解锁 CA。Windows 安装到受信任的根证书颁发机构；Android 安装为用户 CA，但应用是否信任用户 CA 由应用决定。信任范围包含共同根下符合用途的各条证书链。Caddy 继续提供网站证书与 TLS 中间链。

全局可修改程序口令：已解锁后只输入新口令及确认，不再验证旧口令。全部私钥与口令元数据在一个事务中重新加密，失败完整回滚；证书、密钥身份不变。
全局可重置四个 CA：单独确认危险操作，输入根 CA 名称，重新初始化并清除全部 Client。程序口令、SSH 密钥与配置不受影响。
区域、节点、站点、引用关系与服务规则不受重置影响。已导出文件及远端节点不会自动更新。
查看配置、证书、SSH 公钥及导出 CA 公开证书不要求解锁。所有配置修改、Client 启停、私钥使用、发布生成和删除、SSH 部署均要求程序解锁。配置本身仍以明文保存，修改权限由共享业务层检查；这不防止程序外直接修改数据库。
Client P12 导出先要求程序解锁，再单独输入一次明文导出口令。解锁、修改口令、P12 导出口令使用同一个可复用弹窗，支持原地错误提示，不提供“显示口令”开关：解锁时隐藏输入；P12 导出口令显示明文；首次设置及修改程序口令仍需两次明文输入；危险操作确认始终独立。

Client 的 P12 导出默认文件名为“证书名称.p12”；不适合作为文件名的字符替换为下划线，保留中文名称。P12 和信任 CA 导出路径固定在 `~/smooth-caddy-export/` 目录，弹窗只读展示绝对路径，不允许编辑；同名文件覆盖仍需确认。

危险操作确认后必须再次输入当前程序口令，验证通过才执行；已解锁状态不能跳过。此验证使用掩码输入，错误可重试，返回则不执行；不改变进程解锁状态，与 P12 导出口令独立。

危险操作仅限重置 SSH 私钥和重新初始化 CA 私钥。部署、恢复/导入设置、删除存档或条目、覆盖导出文件、信任 SSH 主机及停止任务均采用普通确认（Ctrl+S／Enter），不增加额外口令验证。正常的首次解锁要求不变。

## 完整性检查

编辑允许暂时无效，除唯一性冲突以及新建名称未保存等情况外，不强制在弹窗中修完才保存。
格式、缺失、引用和监听冲突在相关单元格及导航标记，详情在编辑弹窗展示；这些配置错误阻止导出。SSH 路径必填，空路径或无效 IP 同样标记为配置错误并阻止生成；SSH 编辑弹窗在确认时严格校验，错误留在弹窗，不保存。
无统一问题列表。删除区域／节点不阻止；不追踪自由 URL 的隐含节点依赖。
删除区域移除所有节点和站点的相应区域配置，不留下站点悬空区域。
不调用 Caddy 做本地或远端配置预验证，不探测网络／站点实际可达性。

## 离线部署基线

### 设置存档与 JSON

存档保存在 SQLite `settings_archives` 表，载荷与 JSON 导入导出使用同一格式（版本 5，兼容读取版本 1、2、3、4）：名称、创建时间、配置。配置仅包含 regions、nodes、sites（包含各站点的 verify_origin_https）；不包含本机修订号、TLS/mTLS 配置、证书、私钥、DNS 凭据、程序口令、SSH 密钥或主机信任。保留对象 ID、顺序和全部配置选项，站点的 TLS 来源及服务方式属于配置意图，应保留。

保存、导出、导入、恢复共用严格结构校验，拒绝未知版本、额外字段、错误类型、重复 JSON 键和大于 10 MiB 的导入；允许地址、平台或域名尚未填写完整的草稿，不要求具备部署条件。存档名称非空，可重复，通过独立 ID 区分。

恢复与 JSON 导入经普通确认后整体替换当前设置，不合并、不自动保存旧设置，不触碰 TLS/mTLS、SSH 身份或已部署节点。替换使用事务与配置修订号；校验或保存失败保持原状。确认期间配置已变化则拒绝覆盖。

界面 JSON 导出针对选中存档，弹窗预填可编辑的保存路径，经范围提示确认后，原子写入 `~/smooth-caddy-export/settings/<时间>-<唯一后缀>.json`，成功后显示完整路径。JSON 导入通过路径输入框选择文件，先校验再确认替换。

### 部署与离线 .run 导出

部署和 .run 导出仅接受当前设置，不接受存档或旧配置批次；使用存档必须先恢复到当前界面。复用界面所调用的业务校验，在任务开始时固定设置快照，准备所需公共证书，再在内存中生成 Caddy 配置与私有叶子证书。

部署选择 Caddy 版本，按当前节点的 SSH 路径探测版本，仅向版本不同的节点携带二进制；临时组装 `.run` 后先上传全部节点，再逐个部署。导出复用相同配置生成和组包逻辑，始终带完整二进制，并以独立导出口令加密。输出至 `~/smooth-caddy-export/packages/<时间及唯一后缀>/`，每节点一个 `.run`。

不再创建持久化配置批次、生成材料目录或文件哈希索引。操作结束释放内存生成材料、清理本机临时包；公共证书和完整工具缓存独立保留。导出成功的文件由用户保管。全部节点部署成功后尝试清理远端上传包，失败或中止不自动回滚远端状态。

每次生成使用时间加唯一后缀标识本次运行，目标节点仍保存运行配置及最近 5 份成功配置，用于目标机手动回退；本机存档与目标机运行版本是不同概念。

### 权限与检查

安装器预设调用者已具备系统级安装权限，不提供用户级安装模式、不自动 sudo，也不单凭 UID 判断；检查实际可写性和服务管理能力。
Caddy 暂以 root 运行，Debian 使用系统级 systemd，OpenWrt 使用 procd。
前置检查仅涉及 CPU 架构、预选服务管理器、目标路径权限和基础工具，不检查 IP 是否已配置、端口是否占用或网络可达性，不自动安装依赖。

### 固定文件布局

| 用途 | Debian | OpenWrt |
| --- | --- | --- |
| 辅助脚本与启动入口 | `/usr/local/lib/smooth-caddy/` | `/usr/lib/smooth-caddy/` |
| 二进制 | 上述目录的 `binaries/<版本>/<架构>/caddy` | 同左 |
| 各批发布配置、证书和清单 | `/etc/smooth-caddy/releases/<发布时间>/` | 同左 |
| 当前选用发布 | `/etc/smooth-caddy/current` | 同左 |
| 持久运行数据与部署状态 | `/var/lib/smooth-caddy/` | `/etc/smooth-caddy/state/` |
| 安装锁等临时状态 | `/run/smooth-caddy/` | `/tmp/smooth-caddy/` |
| 系统服务定义 | `/etc/systemd/system/smooth-caddy.service` | `/etc/init.d/smooth-caddy` |
| 默认日志接收方 | journald | logd |

OpenWrt `/var` 通常指向临时目录，因此不用于保存这些持久材料。固件升级后的安装保留不纳入当前范围。

### 部署、重试与恢复

包内清单记录节点身份、包格式、平台、架构、确切 Caddy 版本、发布版本及文件校验值；不能依靠文件名判断。
SSH 部署执行 `.run --take-over`，允许无提示覆盖不同节点 ID 的旧部署；此选项仅跳过节点归属确认，不跳过 SSH 主机公钥、平台、架构和材料完整性校验。离线 `.run` 默认在节点 ID 不一致时要求确认（默认拒绝）；拒绝或 EOF 时不替换原部署。安装阶段写入新的节点 ID。
先解包、检查完整性并准备完整新材料，再切换发布，避免在正在使用的目录中逐个覆盖文件。
配置与证书整体切换，服务使用该发布绑定的二进制。启动／重新加载后观察进程持续运行，不运行 Caddy 配置预验证或实际站点访问测试。
失败保留当前选用发布与故障信息，不更新“最近成功发布”、不清理旧发布、不自动恢复；两种状态必须分开记录。
固定辅助入口分别提供“列出本地发布”与“切换指定发布”命令，不要求用户手工编辑符号链接。命令为 `manage list` 和 `manage switch <批次标识>`。

## SSH 部署边界

每个节点独立配置必填 `ssh_hops`，与业务上下游及中继区域无关。使用 root、端口 22 和统一程序密钥，不增加连接类型、用户名或端口选项。第一版每跳恰好一个 IPv4/IPv6 地址；底层每跳保存一个单元素列表，拒绝多个候选地址。后续跳的地址只须从前一跳可达。上游地址修改或删除不改变 SSH 路径。

节点列表的“SSH 路径”列只显示目标 IP，多跳追加 `(+N)` 表示 N 个跳板。编辑为约 48 字符宽、4 行可见高度的多行文本框，3 跳无需滚动，更多行允许滚动；不提供增删、排序或多径按钮。Enter 换行、Ctrl+S 保存、Esc 取消。去除行首尾空白、忽略空行，保留原始行号报告错误；仅接受 IP，拒绝用户名、端口、域名、通配、多播及带 scope 的地址。保存不连接网络。新建节点暂未填写时标记错误，不能生成或部署。部署确认显示节点名称和完整 IP 路径。

首次启动设置程序口令时生成并加密保存一套共用 SSH 私钥，可明确确认后重置。节点信任公钥由使用者按引导手动配置，程序不承担首次密码登录或自动安装公钥。持久记录程序私钥与连接过的节点主机指纹，不保存登录密码；重置程序私钥不清除主机指纹。
主机指纹按从第一跳至当前跳的规范化 IP 路径前缀记录（`ssh_hosts` 表），相同私网 IP 经不同跳板到达时不会混用信任。旧 `hosts` 表保留但不自动复用，升级后须重新确认每一跳。每一跳首次连接须确认主机身份；指纹变化时停止并明确重新确认，不能静默接受。程序私钥不复制到节点。

部署从当前设置固定快照，使用当前证书体系及 SSH 路径。重试完整任务时重新读取当前设置并准备材料，不复用失败任务的历史证书。
全部节点统一确认，暂逐个执行：先依次上传全部安装包，再依次安装并检查服务持续运行。失败暂停，提供重试、跳过、停止；上传跳过的节点不进入安装。停止保留已完成操作，无自动回滚。安装时连接中断不能直接判断失败，应先重连查询结果。

## 实现边界与模块化

当前工程以本文件为产品基线。旧实现和原型已退役，不随程序分发；首次公开发布以前的开发历史仅在本地归档，公开仓库从审核后的干净提交开始。

正式实现是一个 Python 程序，不引入多服务或插件系统。TUI 和未来 CLI 是并列入口，共用独立应用接口层；TUI 不通过执行自身 CLI 子进程实现业务。

应用接口层承接完整业务操作、参数校验、执行流程、结构化结果、进度和需要用户决策的状态，不依赖 Textual，不读取键盘或输出界面。TUI 负责输入、展示和提交用户决策，不直接操作数据库或实现签发、配置生成、打包、部署逻辑。
配置管理、证书管理、Caddy 配置生成、二进制缓存、部署包 管理、SSH 连接及部署执行保持明确职责；跨模块流程由应用层组织，不互相读取内部状态。

CLI 指 Linux shell 中独立执行、完成后退出的命令。可在 TUI 定型后实现；命令格式、参数和 help 由实现阶段确定，每项业务能力最终都须可从 CLI 调用，与 TUI 共用默认值、校验及执行逻辑。验收标准是去掉 TUI 后，业务仍可通过 Python 接口独立调用和测试。

## 交互基线

当前 TUI 作为正式实现的交互基线，后续在使用中微调。键盘可完成全部操作，支持鼠标；普通桌面终端优先，不过度适配小屏；矩阵允许横向滚动，保持名称列和表头，选中项随滚动可见。

### 页面与内容

首屏为部署页。主界面仅有软件标题及三个操作区域：左侧导航、右侧上部内容、右侧底部操作。主界面不展示解释性文案、重复页面标题、状态摘要、选中项说明或消息条；必要解释、错误详情和危险操作影响放入编辑／确认弹窗。

| 导航 | 内容与选择方式 | 条目默认操作 | 其他操作 |
| --- | --- | --- | --- |
| 部署 | 当前设置摘要、节点 SSH 路径与状态 | 无 | 部署、导出 .run |
| 存档 | 设置存档列表，整行选择 | 无 | 当前设置：保存存档、导入 JSON、导出当前 JSON；选中存档：恢复、导出存档 JSON、删除存档 |
| 站点 | 站点 × 区域矩阵，单元格选择 | 编辑 | 新增、删除 |
| 节点 | 节点 × 区域矩阵，单元格选择 | 编辑 | 新增、删除 |
| 区域 | 区域与默认 HTTPS 策略列表，单元格选择 | 编辑 | 新增、删除 |
| mTLS证书 | Client 列表，整行选择 | 无；Enter 不执行动作 | 启用／禁用、签发新增、导出 P12、进入 CA 管理 |
| TLS证书 | 公共证书列表，整行选择 | 详情 | 新增、删除、申请、全部申请、设置、lego 管理 |

CA 管理是 mTLS证书页的二级页面。未初始化时提供“初始化 CA”，已有 CA 时同一入口显示“重新初始化 CA”；后者先确认清除全部证书及 Client，再进入初始化。另提供导出信任 CA 和返回证书。修改程序口令位于设置页顶部；受保护操作自动调用统一解锁弹窗。SSH 公钥及重置功能位于节点页，不放在 CA 页。

节点列顺序为：**名称、平台／架构、SSH 路径、绑定地址(区域名)、上游地址**。

- 平台与架构合并展示，编辑框仍是两个独立选择项；任一项错误均标记在合并列。
- 新增／编辑名称只输入名称，不提供父节点或连接类型选择；名称列不显示树形缩进。
- 上游地址为最后一列，直接显示 URL；留空显示“直达源头”。编辑为单行 HTTPS 地址输入框，说明留空直连源头，填写时必须指向已存在的中继服务地址和端口，并提醒避免环路。保存前校验 URL，失败留在弹窗；可明确清空以直达源头。
- 区域单元格集中编辑启用、多行绑定地址（4 行可见高度）、HTTP／HTTPS 两个端口覆盖开关（默认 80／443），以及“启用中继服务”勾选框与端口输入（默认 8443）。中继默认关闭，开启后直接填写端口。三个端口均仅作用于当前节点的当前区域。
- 站点按名称、域名、源地址、各区域排列，区域服务规则在区域单元格中编辑。

新增先输入唯一名称；保存名称后保留新行，继续复用已有条目的编辑行为。未保存名称时取消，不产生条目。删除节点不改写其他节点的上游地址 URL 或 SSH 路径；删除区域仅移除相关监听与站点区域规则。
Client 名称固定，不能改名或单独删除。选中行后，底部普通按钮随状态显示“启用”或“禁用”，不使用默认重点色或 Enter 提示；按钮、Ctrl+T 调用同一切换操作。

列表使用持久化顺序，切换页面或编辑名称不会重排，新建条目追加到末尾。

节点、站点、区域和公共 TLS 证书列表支持 F7 / F8 上移／下移手动排序，立即保存并保持选中条目及列；首尾不循环。仅列表焦点且无弹窗时生效，不增加按钮或提示，仅在帮助记录快捷键。新增条目追加末尾，区域顺序同步到站点和节点的区域列。各页面及关联展示、部署确认、筛选后的条目保持对应配置的相对顺序，不按名称或 ID 重新排序。顺序不改变 SSH 路径或认证策略，历史批次不改写。

### 导航与焦点

主界面 Tab／Shift+Tab 在导航、内容、底部操作三者之间循环；方向键只在当前区域内移动。

- 导航主模块随方向键高亮即时替换右侧内容，焦点仍留在导航。Enter／空格选定页面并进入内容区。
- 帮助、退出位于侧栏，移入焦点不切换页面、不执行动作，确认后才执行。
- 内容区方向键移动单元格或行；底部操作栏方向键在可用按钮间循环。
- 弹窗使用独立焦点范围，Tab／Shift+Tab 在弹窗控件间移动；不响应主页面导航快捷键。
- Esc 依次退出展开控件、弹窗、二级页面；主页面无可退出层级时返回导航。已在导航时再次 Esc 不退出程序。进行中的任务先确认停止。

Enter 执行当前焦点控件的默认操作，不由全局 Enter 抢占。配置单元格打开编辑，部署与存档行不执行默认操作；证书行无默认操作；按钮焦点下 Enter 点击该按钮。危险确认框例外：Enter 和 Ctrl+S 均不执行确认，使用 Ctrl+Y 或鼠标点击确认按钮。危险确认按钮统一使用红色，焦点仍遵循全局蓝色；返回按钮在显示快捷键时标注 Esc。

- Ctrl+N：当前页新增；存档页为保存当前设置，部署页不新增条目。Delete：支持删除的当前条目。

- Ctrl+S：普通表单保存／流程确认／关闭结果。Ctrl+Y：危险确认，仅重置 SSH 私钥和重新初始化 CA 私钥。
- Ctrl+O：编辑当前配置单元格。
- Ctrl+E：当前页面导出；证书页导出选中 Client 的 P12，CA 页导出信任 CA，部署页导出选中节点的 .run 安装包，存档页导出选中存档 JSON。
- Ctrl+D：在其他主页面进入部署页，在部署页部署选中节点。
- 部署暂停时在处理方式中选择重试、跳过或停止，再用 Ctrl+S 确认。

界面文案约定：普通确认按钮使用“确认”，表单使用“保存”；解锁、额外口令验证、P12 导出分别使用“解锁”“验证”“导出”。任务重试统一为“重试”。帮助与当前导航、详情入口保持同步；设置 JSON 导出与 .run 安装包导出明确区分。

帮助页展示项目使用说明：模块职责、推荐配置与部署顺序、证书更新及网络配置边界，不再列出快捷键。长文可滚动阅读，底部只保留返回按钮；F10 三态循环不变。

使用说明末尾列出 Caddy 的 Apache-2.0 许可证、lego 的 MIT 许可证与 Let’s Encrypt 订户协议入口，区分软件授权和证书服务条款，并说明调用 lego 会传入接受条款选项。以官方原文为准，不在界面复制整份协议。

### 视觉与错误提示

软件标题、激活导航、未聚焦的默认操作共用墨绿色重点色；标题使用终端原生字号、加粗和上下留白，不单独改变字号。
光标统一为蓝色：导航焦点背景覆盖激活背景，内容区单元格／行使用蓝色，所有区域的按钮聚焦时整块变蓝，包括上下边缘。危险按钮未聚焦时保留警示色；首列不使用特殊底色。

按钮最小宽度为 16 个终端字符格，按实际可见文案计算；隐藏快捷键时短按钮基本同宽，显示快捷键或文案较长时扩展。文字水平、垂直居中；必要时增加一格，使中英文混排的左右空白对称。

配置错误是主界面精简文案规则的例外：相关导航显示单个 `!`，标签为红字，不显示错误计数；激活或聚焦时仍保留红字，修复后恢复。相关表格单元格保留错误标记，详细原因在编辑弹窗显示；无全局问题列表。

表格采用两级选中提示：单元格模式下，当前整行使用浅蓝色背景，选中单元格使用统一光标蓝色。整行选择模式下，全部单元格（含固定首列）使用相同蓝色；焦点移到导航或底部操作按钮后，选定行保持原色，不套用不同的失焦颜色。

导航顺序为部署、站点、节点、mTLS证书、TLS证书、设置，对应 F1～F6。滚动条统一为中性灰色。节点、站点、区域名称列宽为 11，mTLS 证书名称列保持 18，TLS 域名列固定为 32，不随窗口拉伸；平台架构列宽 20，SSH 地址列按各行显示宽度在 18～46 内调整，端口列按标题宽度紧凑排列。

### 部署页面流程

部署页展示待部署配置总览：首列标题为“节点”，第一行为节点名称，第二行为最终 SSH 地址，不展示跳板路径；每个节点至少两行。后续列按区域配置顺序排列，启用区域先逐行显示绑定地址，沿用节点页逻辑：HTTP/HTTPS 默认端口只显示 IP，有覆盖端口时显示 IP:(HTTP/HTTPS)，中继开启时追加“·中继”，不展示中继端口，再按站点配置顺序逐行显示“站点名称  服务方式”（每个站点行前缩进两个空格，与绑定地址错开；同一区域按最长站点名的终端显示宽度补齐名称，使服务内容对齐，mTLS 紧跟 TLS；错误标记置于行尾），过滤关闭站点；关闭区域显示“未启用”。IPv6 地址加方括号，地址与端口之间无空格。错误标在相关内容处，不展示上游和状态列。节点行保持节点配置顺序。左侧“导出 .run”“部署”针对选中节点，右侧“全部导出”“全部部署”针对全部节点；进入相同的 Caddy 版本选择流程，弹窗明确显示范围和节点名称。列表没有默认操作，回车不触发导出或部署。单条操作只为目标节点打包、探测、上传和部署，不修改当前设置。存档页单独显示名称、保存时间、节点/站点/区域数量，底部单行靠左依次显示“新增存档、载入、删除、导出”。新增存档保存当前设置为新条目，其余操作针对选中存档；不设默认操作，列表回车不触发动作。移除常驻范围说明，新增、载入、导出和导入弹窗展示范围提示。存档本身没有部署按钮，恢复后须切换部署页操作。

## 当前实现与数据约定

默认入口为 `smooth_caddy.py → app.entry → app.tui`。旧实现与内存原型已归档，不随程序分发。

业务层位于 `app/network/`：`models` 定义配置与校验，`storage` 管理 SQLite 与配置修订，`application` 提供编辑命令，`certificates` 管理 Python PKI，`generator` 生成节点材料，`archives` 管理数据库存档及 JSON，`releases` 管理二进制缓存、旧批次读取及临时打包，`deployment` 管理 SSH 信任及分阶段部署。所有业务模块不导入 Textual；当前先交付 TUI，完整 shell 命令面后续接入相同接口。

运行数据写入 数据目录内的 `smooth-caddy.db`，仅对支持的正式版本执行备份后的事务迁移。数据库有独立所有权标记与版本检查；配置保存使用修订号避免覆盖并行修改。`security` 负责共享口令会话及私钥加密；Scrypt 从口令和随机盐派生密钥，Fernet 提供认证加密。全部持久私钥均在数据库内加密，无独立解密文件。口令和解锁材料只保留在进程内，不写日志或配置；退出释放引用，不承诺 Python 内存物理清零。已生成安装包中的运行私钥保持可由目标机直接使用，P12 使用独立口令。

正式安装模板位于 `app/network/templates/`。私有证书数据库保留 CA 与用户 Client，公共模块另行持久保存公共材料。打包时使用本次内存生成材料，内部安装清单仍记录节点、架构、目标 Caddy 版本和校验值；导出的 package 没有额外持久记录。

官方版本列表查询失败时，弹窗显示具体失败原因，保留本地版本供选择。GitHub 返回包含资产与说明的完整发行元数据，版本列表请求允许最多 16 MiB，避免将正常响应误判为超限。

部署与导出 package 的版本选择以版本矩阵当前行为准，不允许手动指定版本。联网刷新保留选择，无候选版本时禁用操作。存档不查询或绑定 Caddy 版本。

SSH 部署返回非零时，失败弹窗同时保留退出码、标准输出和标准错误，并尝试限时读取最近的服务日志；不因诊断停止其他服务或自动修改监听端口。

运行材料标识使用 `YYYYMMDD-HHMMSS-<8位十六进制后缀>`，避免同秒生成冲突。安装、切换、列表和清理使用同一名称规则，并兼容旧的纯时间戳标识；清理保留当前版本和最近成功版本（合计最多 5 个），不删除仍被版本引用的材料。

正式安装器在重启前记录旧 PID；重启后最多观察 30 秒，忽略旧 PID 和进程交替的空档，仅在新 PID 连续存活 3 秒后确认成功。未达到条件仍失败并保留现场，不自动回滚。此检查不验证站点可达性。

设置存档保存在数据库；临时包及 .run 导出使用固定目录，不提供目录编辑。版本列表先展示缓存，后台联网刷新；不可选的刷新提示完成或失败后移除。

版本列表缓存同时保存 HTTP ETag／Last-Modified；后续使用条件请求，304 时直接复用本地 JSON，不下载完整响应。校验元数据与缓存内容对应，避免损坏或旧缓存误用。版本查询网络等待为 10 秒，界面刷新总等待上限 20 秒；超时结束刷新提示并保留已有列表。

旧批次仅接受索引格式 3、metadata 格式 1～5。启动时校验原 metadata 哈希并提取设置，按原批次标识一次性转入数据库存档；不解密或读取证书材料，不改写旧目录或索引。删除迁入的存档不会在下次启动重新导入。旧文件由用户自行保管。

取消禁止兼容层的限制。以首次正式发布格式为兼容基线，不追溯支持所有开发期格式。后续持久数据升级使用显式版本迁移，迁移前备份，遇到更新格式拒绝写入。程序版本与数据库、批次、部署包格式版本分别管理。当前数据库版本为 11，接受版本 2、3、4、5、6、7、8、9、10 并自动迁移，版本 1 等开发期格式不支持。迁移持有 SQLite 写事务锁，先用 SQLite backup API 生成包含全部表的完整备份并校验，再转换配置、递增配置修订号并更新数据库版本；任一写入失败回滚，备份失败不得继续。备份存入数据目录 `backups/smooth-caddy-v<旧版本>-<唯一标识>.db`，不自动清理；重新打开已升级数据库不重复备份。SSH 路径沿旧关系展开后去掉旧 `ssh_ip` 字段，任何缺失地址、断链或循环都将整个 SSH 路径置空，由必填校验标错，不生成残缺路径。用户名称、ID、端口、证书及加密材料保持原样。旧上游地址引用按原监听 IP 与中继实际端口解析为 HTTPS URL，并删除 `mode`、`upstream` 字段；缺失或关闭的旧目标、无效地址或端口保留为无效的 `https://`，阻止生成，必须人工修复或明确清空，不能静默变为直达源头。升级前应退出旧程序；旧程序拒绝打开数据库版本 10。旧绑定字段 `ip` 转为 `ips` 单元素列表，空值转为空列表，不改变端口及禁用状态。配置批次索引仍为 3，部署包格式仍为 1。

Caddy 二进制下载以分块进度展示版本、架构、进度条、已下载／总大小及平均速度，并明确区分校验清单、连接服务器、下载、校验解压和使用本地缓存。服务器未提供总大小时使用不定进度，保留已下载大小和速度，不推测百分比。下载完成后继续显示证书生成及节点打包阶段。

### 统一任务进度

确认后总步骤一次固定：所需公共 TLS 证书准备、内存生成运行材料、节点部署（探测、准备 Caddy、组包、上传、安装）。.run 导出使用同样的前两组，再准备完整二进制并组包。没有公共 HTTPS 站点时省略证书组；下载数量不改变固定总步数，无需下载时明确显示。

统一展示最多两级任务。只有一个大任务时只展示子任务；多个大任务时展示大任务及其子任务。大任务串行，子任务由业务决定串行或并行，固定顺序展示、独立记录状态，乱序完成不能推断其它任务完成。大任务显示已结束子任务数，失败单独标识；总体进度以大任务数（单组时以子任务数）计数。总体进度和耗时位于同一行。返回在执行期间禁用，Esc 不关闭正在运行的任务。停止需要独立确认并等待安全检查点；生成批次不发布残缺数据，临时打包的失败产物清理，缓存始终复用。失败可重试，不自动回滚或恢复；探测只允许重试、停止，部署支持重试、跳过、停止，远端结果未知时先查询。

完成或失败保留同一弹窗，不叠加成功提示。运行标识及各节点结果融入对应子任务行，不另行重复汇总；仅 package 导出成功显示输出路径。主机指纹确认独立于任务确认。

进度列表每一步均显示状态或结果：探测仅显示实际版本（无版本时显示未部署），打包仅显示已打包，上传及部署显示实际结果；尚未执行的步骤显示等待中或未执行，失败及跳过不标记为成功。

## 独立公共 TLS 模块

主导航提供“TLS证书”独立页面。模块独立负责配置、申请、数据库存储及 lego 管理；站点通过 TLS 来源选择使用已有公共材料，组合流程负责按需申请及运行材料生成。私有 CA 重置不清除公共 TLS 记录。

- 仅使用 Let’s Encrypt，模块级测试模式默认开启；测试与正式环境共享配置条目和 DNS 凭据，证书、私钥、有效期、错误及 ACME 状态分别保存。切换环境仅切换申请结果，不跨环境使用证书；已启动的申请固定使用启动时的环境。
- 每条记录独立填写域名、通配选项、DNS 服务商及凭据。支持阿里云和 DNSPod（lego 的 tencentcloud），不聚合、不共享、不继承凭据。
- 通配申请同时包含基础域名及其一级通配域名。域名范围保存后固定；改变范围需新增记录。编辑凭据时留空保留，更换服务商必须重新填写。
- 新增只保存配置；详情提供申请、强制申请和编辑。申请成功后校验域名、有效期、证书与私钥匹配及提供的证书链签名，再原子替换材料；失败保留旧材料。尚未签发的记录可保存。
- 普通申请复用剩余有效期超过 13 天的材料；其他情况交给 lego 执行。强制申请重新请求材料。使用统一任务进度框，无后台定时续期。重新准备运行材料时按需申请或续签。域名全局唯一，通配与否不影响唯一性。全部申请对当前环境的记录最多并发 3 条，复用无需更新的证书；失败不影响其余记录，停止取消在途任务并不再启动等待记录，保留已完成结果。
- 现有数据库的键值表以 public-tls/ 保存公开元数据，以 public-tls-secret/ 加密保存每条记录的 DNS 凭据、私钥和 lego 工作状态。纳入统一口令修改事务，后续结构升级纳入统一版本迁移。
- 执行时恢复至权限受限的临时工作目录，结束后删除。ACME 账户失效时重建该记录的账户并重试一次。中断、网络错误可能留下 DNS 验证记录，不把本地停止视为云端撤销。
- lego 管理显示本地版本，手动检查官方最新兼容 v5 版本，按运行主机平台和架构下载；核对官方 SHA256 清单、执行版本检查后原子替换，失败保留旧工具。工具文件位于 数据目录内的 `tool_lego/lego`，不入数据库、不下发节点；签发不自动下载更新。
- 首版自动化测试使用 ACME 与 DNS 替身，不表示真实 DNS 服务商申请已验收。

### 站点公共 TLS 与运行材料生成

- 每个站点区域的 TLS 来源继承区域默认或显式选择私有 CA／公共 CA；区域初始默认私有 CA。中继证书仍使用专用私有 Relay CA。
- 当前公共 TLS 环境内按精确域名优先、一级通配其次匹配，不手工绑定条目。生成时验证实际证书覆盖范围及私钥，不回退到私有 CA。
- 统一本地检查区分阻断错误（无匹配配置、损坏材料、解锁后发现 DNS 凭据缺失或密钥不匹配）和待处理状态（待申请、待续签）。后者展示在对应站点区域单元格，不阻止进入流程。锁定时不解密材料；解锁执行前重新校验。
- `app/network/batch_workflow.py` 编排公共证书准备与运行材料生成，TUI 不实现业务编排。只对需要 HTTPS 的站点匹配记录，去重后最多并发 3 条；不申请无关记录。任一申请失败则停止生成，保留已经成功签发的材料。
- 首先固定全部任务及分组，再开始执行；申请结束重新核对配置、环境和材料。证书与私钥通过明确参数传入底层生成器，生成器不查询公共证书库、不访问 ACME。
- 批次保存公共完整链和私钥快照，不追加私有 CA 链；私有站点证书及中继身份仍按原流程生成。已有批次的部署和导出不触发签发，也不依赖当前公共 TLS 记录是否存在。
- 测试环境生成确认提示“包含公共 CA 测试证书”。没有公共 HTTPS 站点时省略公共证书阶段。

## 当前实现结构

生产入口只使用 `app/network` 和 `app/tui`，旧实现、原型和独立实验脚本已归档退役。当前测试只覆盖受支持的入口和产品功能。

TUI 通用弹窗在 `dialogs.py`，区域／节点／站点编辑在 `configuration.py`，使用说明在 `guide.py`，公共 TLS 和部署页面分别在各自控制器中。页面刷新共享一份 `ValidationReport`，不逐单元格全量校验；执行任务前和证书申请后重新检查。

域名唯一性共享规范化规则。公共证书预检查与续签使用 `certificate_policy.py`；底层 HTTP 下载使用 `downloads.py`，原子写入使用 `files.py`。任务计划及状态约束见 [任务系统](supertaskrunner.md)，证书接口见 [证书模块](ca-lite-interface.md)。

自动测试使用临时数据库、网络与 SSH 替身，不等同于真实 DNS 签发、Debian/OpenWrt 实机、自启动、恢复和跨架构验收。

## 程序发布与文档

程序的版本、构建、发布及第三方许可处理以[开发与发布](development.md)为准；下载、备份与升级步骤见[使用指南](usage.md)。本文件维护配置模型与交互规则，不重复维护操作流程。

项目名称为 Smooth Caddy，命令与服务名为 `smooth-caddy`，源码入口为 `smooth_caddy.py`。数据库文件继续使用 `smooth-caddy.db`；数据库所有权与加密校验常量属于存储格式，不随品牌名改变。旧配置批次固化了旧部署路径，改名后应重新部署当前设置；目标机旧服务须由用户停用，新服务不自动接管旧目录。

独立程序和源码运行均通过 `Path.home()` 确定用户主目录，默认数据目录为 `~/.smooth-caddy/`，支持 `--data-dir` 覆盖；内置样式和部署模板继续从资源目录读取。构建输出包括单文件程序、说明、许可证目录、构建环境记录与压缩包 SHA-256。当前许可证收集仅作为审核材料，不声明已完成公开分发审核。

CA 管理无需解锁即可查看公开证书树：根节点展示实际根证书 CN，下一层依次为 Relay CA、TLS CA、mTLS CA；Relay、TLS 下显示省略号，mTLS 下展示已签发 Client，禁用者标记 `[disabled]`，无 Client 时显示“暂无证书”。各实际证书的到期日期独立右对齐，读取证书内容；不显示解锁状态。新建 CA 前缀及 Client 名称只允许 ASCII 字母、数字、空格、连字符、下划线、句点，保存时去除首尾空格；已有名称保持原样。

首次启动以一个“初始化”弹窗收集初始化口令、确认口令与初始化根CA名称。按钮为“退出”和“保存”；保存后生成受统一口令保护的 SSH 密钥及四个 CA，不再分两次填写。提示文案为：“使用本软件前，必须设置一个口令。本程序将生成SSH密钥及根CA私钥，私钥均将受到以上口令保护。请妥善保管本程序的口令及数据目录。”新口令两次输入保持明文展示；校验失败留在原弹窗，退出不创建材料。

界面文案使用名称、用途及实际状态，不将内部操作流程写成提示。字段使用“名称”等简短标签；输入限制、错误原因、凭据保留规则、服务条款及删除／重置风险保留必要说明，操作引导集中在使用说明中。

同一数据目录只允许一个运行实例。启动持有单实例锁，在后台线程清空数据目录内的 `.tmp/`，清理完成前不启动业务任务；退出等待任务结束后在后台线程清理，再释放锁。下载、解压、ACME 工作文件与导出中间材料都使用数据目录内的 `.tmp/`。证书导出到 `~/smooth-caddy-export/`，部署包导出到 `~/smooth-caddy-export/packages/`，完整生成后发布，失败不覆盖已存在的导出文件。导出目录通过 `Path.home()` 定位，在导出时创建，不随 `--data-dir` 改变；内部记录相对路径，界面展示绝对路径。
部署导航始终可用，默认进入部署页面；配置缺失或错误沿用校验提示。首次初始化在未编辑过的空配置中加入 Private、Public 两个区域，HomeRouter、CloudServer1、CloudServer2 三个节点，以及 Blog、Dashboard 两个站点。初始内网（Private）与外网（Public）均使用私有 CA，内网关闭 mTLS、外网开启 mTLS，示例站点均继承区域策略。节点平台、地址、上下游及站点域名、源头采用初始化示例；不自动创建公共 TLS 申请配置、不申请证书或部署。后续启动及 CA 重置不重复添加、不覆盖已有配置。

节点的绑定地址列默认逐行显示 IP，IPv6 使用方括号；HTTP／HTTPS 端口不同于内置默认值时显示这两个端口，例如 `192.168.10.1:(81/443)`，无额外空格。中继开启时在每个地址后追加“·中继”，例如 `192.168.1.1·中继`、`[::]:(81/443)·中继`；中继关闭时不追加。中继端口不在列表中展示，也不触发端口组展示。取消 HTTP／HTTPS 端口覆盖恢复内置默认值；中继关闭保留已填端口但不监听。节点每条至少两行，平台与架构分行；SSH 地址第一行显示最终目标（IPv6 加括号），有跳板时第二行显示“(经X个地址跳转)”，编辑仍为多行路径。节点行高随各单元格行数展开。节点列表不提供独立 HTTP 跳转端口列，统一从绑定地址弹窗编辑。上游列名为“上游”，无上游显示“直连”，有上游第一行显示“中继”、第二行显示完整 HTTPS 地址。部署总览复用相同地址展示逻辑。


旧配置批次材料使用独立随机 Fernet 密钥进行认证加密，批次元数据及列表摘要保持明文。密钥初始化时生成，经程序口令加密保存在数据库，不提供修改入口；修改程序口令仅重新加密此密钥，CA/SSH 重置不影响它。读取批次材料须解锁。
手动导出的部署包使用独立口令加密载荷（AES-256-CBC、PBKDF2-HMAC-SHA256、100000 次迭代、随机 8 字节盐，派生密钥及 IV），不增加身份认证或防篡改机制。导出口令明文输入一次，同次导出的各节点共用口令但各自随机盐。目标机需要 openssl 命令，交互输入口令后解密部署；口令不进入包内或命令行参数。SSH 部署仍生成临时明文包，经 SSH 传输，结束后清理。

数据库版本 9 将区域端口实际值固化到节点区域，区域仅保存默认 HTTPS 策略。旧 HTTP 服务转为 HTTPS＋私有 CA＋关闭 mTLS，其余服务策略显式保留原值。版本 2～7 的各区域三个实际端口分别保留；版本 8 的节点 HTTP 端口复制到该节点所有区域，然后移除节点级字段。存档／JSON 新格式为 5，兼容读取格式 1、2、3、4，应用同一迁移规则。迁移前完整备份，不改写旧备份。

交互优先使用直接可见的候选单选项和布尔勾选框，尽量避免下拉选项。区域 TLS 来源使用“私有 CA／公共 CA”候选单选，mTLS 开关使用勾选框。

站点区域编辑为三行：启用此区域／自定义配置，私有 CA／公共 CA，关闭 mTLS／开启 mTLS。后两行各自互斥，禁用服务时其余控件置灰；未选自定义时后两行显示区域当前默认且不可编辑，取消自定义立即恢复默认值。自定义以整组保存两个显式值，否则两个覆盖值都为 null。已有单项覆盖在编辑时按当前生效值显示为整组自定义，保存后固化两项。表格与部署总览中，私有 CA 显示 TLS，公共 CA 显示 TLS(公共CA)，仅启用 mTLS 时追加 ·mTLS，不显示 HTTPS、关闭 mTLS 或继承标记；公共证书待处理状态仍保留。

上游编辑使用两行：首行“直连／中继”互斥候选，第二行 HTTPS 地址。仅选择中继时允许输入且地址必填，直连保存空字符串；数据格式仍为 upstream_url。站点服务显示如 TLS(公共CA)·mTLS；部署总览名称与 TLS 之间仅用对齐空格，不用分隔号，TLS 与 mTLS 之间使用 ·。
站点区域列以服务文案实际终端宽度加留白计算，最少 20 格；名称、域名、源头列分别按内容调整。部署首列至少 22 格，区域列至少 34 格，按每行实际显示宽度扩展；超出窗口时允许横向滚动。候选行复用通用表单的方框勾选控件，互斥组选项始终且仅有一项选中。站点、上游、区域 CA 与区域 mTLS 共用表单外框、底部按钮、行高和间距；不使用独立的 RadioSet 样式。

站点、节点、部署表格中的未启用区域统一显示“未启用”，站点和节点区域编辑开关统一为“启用此区域”。部署页面不显示当前配置数量及校验摘要；配置校验与操作阻断保持有效。

数据库版本 10 将全局 verify_origin_https 复制到各站点并移除全局字段，迁移前完整备份。新站点默认为 false；JSON 格式 4 使用同一规则读取旧格式。

表单方向键切换焦点时包含绑定地址和 SSH 地址的多行输入框；进入多行输入框后方向键用于移动文本光标，Tab／Shift+Tab 切换控件。

设置是主导航第六项（F6），部署保持第一项（F1）及默认启动页。进入设置默认展示区域；顶部左侧以区域／存档按钮平级切换，右侧依次为导入配置、修改口令。导入配置属于设置全局功能，在区域与存档子页均可使用；确认后直接替换当前配置，不新建存档。区域与存档复用原有表格及操作，口令弹窗关闭后保留当前子页与焦点。设置页 Tab／Shift+Tab 在主导航、设置顶部、内容区、底部操作区之间循环；方向键在顶部按钮间切换。区域校验错误归集到主导航设置项。

交互一致性规则：主页面编辑、新增、删除、导出、部署、排序及导航快捷键不穿透弹窗；弹窗保留自身保存、返回和文本编辑行为。未支持的删除／Client 启停操作不触发解锁。存档新增、删除、导出分别沿用 Ctrl+N、Delete、Ctrl+E，部署及 .run 导出沿用 Ctrl+D、Ctrl+E，F10 展示对应按钮提示。存档导出预填 `~/smooth-caddy-export/settings/<时间>-<唯一后缀>.json`，独立于数据目录，可修改；空路径和目录不能保存，覆盖已有文件需普通确认。设置顶部操作支持窄窗口横向滚动。

逐页交互约定：站点、节点、区域列表回车编辑当前单元格；TLS 证书列表回车查看详情；mTLS 证书、部署、存档列表无默认操作。Tab／Shift+Tab 切换主页面操作区，弹窗内切换控件；单行输入左右移动光标、上下切换焦点，多行输入方向键编辑文本、Tab 离开。任务进行中不能返回，停止经确认；失败用 Ctrl+S 重试，结束后 Esc 返回。CA 页 Esc 返回 mTLS 证书页，其余主页面 Esc 回到导航。

按钮颜色只表达导航与焦点：绿色仅用于选中的导航项（包括设置子页）。普通按钮为中性色，获得焦点时为蓝色；列表获得焦点且有条目时，其回车默认操作按钮同步显示蓝色，焦点移开或打开弹窗后取消。站点、节点、区域默认编辑，TLS 默认详情，版本选择列表默认部署／导出；部署、mTLS、存档列表不标默认按钮。表单输入框中的 Ctrl+S 不使保存按钮高亮。危险按钮始终红色，焦点以粗体下划线区分，不能被蓝色覆盖。

焦点进入左侧导航区（含帮助、退出）时，右侧列表隐藏光标和行强调，默认操作按钮取消蓝色；保留选中条目和单元格位置，焦点回到右侧后恢复显示。
